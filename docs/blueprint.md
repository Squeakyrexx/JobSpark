# **App Name**: JobSpark

## Core Features:

- Resume Toggle: Displays a resume toggle which dynamically affects match score visibility, enhancing the user experience.
- Search Filters: Job search functionality with fields for job title, desired salary, and location to narrow down the search.
- Loading Animation: Show a loading shimmer after the 'Search Jobs' button is pressed and before results render.
- Results Display: Displays six mock job results formatted as code blocks with key details like job title, company, and match score.
- Cover Letter: Mock cover letter generation: selecting this produces a popup informing users that cover letter generation is 'coming soon'.
- Resume Management: Basic UI that allows users to 'upload' or swap out a resume for enhanced results (no backend).
- Generate Insights: Generative AI tool that identifies common skills, requirements, and salary trends. Generates tags and chips for display.

## Style Guidelines:

- Primary color: Light lavender (#E6E6FA) for a calming, professional feel.
- Background color: Off-white (#F8F8FF), providing a clean and spacious backdrop.
- Accent color: Soft sky blue (#B0E2FF) to highlight key elements without being too distracting.
- Font: 'Inter' (sans-serif) for body and headline, providing a modern, readable, and clean interface. Note: currently only Google Fonts are supported.
- Code font: 'Source Code Pro' for clear display of job details in a code-block format.
- Use soft shadows and 2xl border-radius on cards for a modern, tactile feel.
- Incorporate page transitions with fade-in/out effects to maintain a smooth user experience.
